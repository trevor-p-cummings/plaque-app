We are building a mobile app that gamifies historical plaques.

Stack:
- Expo React Native
- Supabase
- TypeScript

MVP:
- map of nearby plaques
- plaque detail page
- GPS check-in
- photo upload
- short story
- AI narrative
- quiz
- points/badges

Rules:
- keep code simple
- use server functions for AI calls
- never expose secrets in client code
- do not invent historical facts
- only generate narratives from supplied plaque data
- run lint and typecheck before finishing
